Privacy Policy

boulder-vault-uploader is a personal, single-user tool that uploads videos created by its sole operator to the operator's own social media accounts (YouTube and TikTok).

It has no other users. It does not collect, store, process, or share any personal data or platform user data from anyone. It accesses only the operator's own accounts, via each platform's official OAuth flow, solely to upload videos.

YouTube API Services

This tool uses YouTube API Services to upload the operator's own videos to the operator's own channel. By using it, the operator agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool stores only its own OAuth tokens (on the operator's private server) and the operator's own video files. It does not access, collect, store, or share YouTube user data belonging to anyone else, and it uses no cookies. Stored tokens can be deleted at any time by the operator, and API access can be revoked at any time via Google security settings.

API data handling complies with the Google API Services User Data Policy (including Limited Use requirements) and the TikTok Developer Terms.
